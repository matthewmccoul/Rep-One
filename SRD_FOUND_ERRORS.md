# SRD found errors (corrected in the published SRD)

## What counts as canon

1. **The reference game is OpenDejenol, and its code is canon.** This project reproduces OpenDejenol's mechanics, not the original Mordor's. Where OpenDejenol deliberately differs from the original game (its "port deviation" notes), OpenDejenol wins; original quirks matter only where OpenDejenol reproduces them.
2. **The SRD is not canon.** It was written from several sources, including the original game's community material, and contains errors. Where it disagrees with OpenDejenol, OpenDejenol wins and the SRD is corrected.
3. **The original Mordor is not the target and has not been checked.**
4. **Where OpenDejenol is silent,** nothing is canon: the SRD rule or the code's choice stays, marked `UNKNOWN`.

Each item was found by comparing the SRD with the reference code; where a reference assertion is named, it passes against the corrected code. The published SRD has been corrected in place. Chapter numbers are the SRD's.
